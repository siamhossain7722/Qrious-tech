★ Is using the AI Job Agent safe for my LinkedIn account?
▾
Yes! The agent runs using Playwright browser automation with human stealth behavior — including randomized mouse movements, natural typing delays, and realistic browser headers. It never makes direct unauthorized API requests.
★ How does Gemini AI write personalized cover letters?
▾
When a job listing requires a cover letter or screening questions, our integration sends the job description and your parsed CV to Google Gemini 1.5 Pro. Gemini crafts a customized 200-300 word cover letter matching your experience to the job requirements in 2 seconds.

▾
Absolutely. You can set exact target job titles, target cities/countries, workplace type (Remote, Hybrid, Onsite), experience level, and set a minimum CV Match Score (e.g. only apply if match is > 75%).
